Frequently asked questions

Does this editor change my live website? Saving updates your local website automatically while START_AUTO_UPDATE.bat is running. Upload dist/ to update public hosting. A Git-connected host can then rebuild and deploy when the changes are pushed to your repository.

Do I need Node.js? Not for the public website. To run the optional local auto-updater, install Python 3. No Node.js is needed.

Will changes remain if I close this editor without downloading? Yes, after a successful save or local publish. Unsaved edits are lost when you close the editor.
